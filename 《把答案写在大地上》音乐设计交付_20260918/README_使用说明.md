# 《把答案写在大地上》音乐设计交付

本文件夹是6分钟、36镜头微电影的配乐与声音执行包。

## 文件

- `《把答案写在大地上》整体音乐设计方案.docx`：完整七部分方案，适合导演、配乐师和声音后期审阅。
- `《把答案写在大地上》镜头-音乐对应关系表.xlsx`：后期直接筛选和执行的工作表，包含镜头映射、Cue、AI Prompt、版权资源、音效和检查项。
- `《把答案写在大地上》镜头音乐数据.json`：结构化数据，便于导入剪辑/制片工具。
- `版权署名模板.txt`：采用CC BY 4.0备选曲时直接复制并替换曲名。

## 默认执行决定

优先制作M01-M06六首AI原创Cue。前33.5秒无配乐，镜头30为唯一和声峰值，镜头33不叠加外部配乐。版权曲只作为整段替代方案，不与原创Cue混搭。

## 技术基线

音乐与音效统一48kHz/24bit WAV；Cue保留前后2秒把手；建议成片-16 LUFS±1、True Peak不高于-1 dBTP。

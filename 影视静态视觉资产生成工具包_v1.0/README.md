# 影视静态视觉资产生成工具包 v1.0

这是一个项目无关的影视前期静态视觉资产工作包，用于把文字剧本、人物设定和镜头脚本转换为可持续复用的角色参考图、道具参考图、场景空间母版和镜头关键帧。

本工具包只处理静态图片和相关文本，不包含视频运动生成内容。

## 适用范围

- 写实剧情片、微电影、短片、广告叙事和纪录剧情类项目。
- 需要长期锁定人物、服装、场景、道具、时间、光线和空间关系的图像生成工作流。
- 需要多人、多场景、多镜头连续生成，且希望减少换脸、左右手错误、道具消失和建筑漂移的项目。

## 快速开始

在PowerShell中运行：

```powershell
.\scripts\New-VisualProject.ps1 -ProjectName "项目名称" -DestinationRoot "D:\目标目录"
```

脚本会复制`project_template`并自动替换项目名称。随后按以下顺序填写：

1. `00_项目简报.md`
2. `01_统一视觉规范.md`
3. `02_角色视觉资产.md`
4. `03_道具视觉资产.md`
5. `04_场景空间母版.md`
6. 先生成角色、道具和场景母版，再填写并生成`05_镜头关键帧清单.md`
7. 每轮生成后执行`07_连续性审核表.md`
8. 把最终文件写入`09_正式资产索引.json`
9. 用校验脚本检查正式资产。

## 自动检查

```powershell
.\scripts\Validate-VisualProject.ps1 -ProjectRoot "D:\目标目录\项目名称_视觉资产"
```

生成正式关键帧联系表：

```powershell
.\scripts\Build-ContactSheets.ps1 -ProjectRoot "D:\目标目录\项目名称_视觉资产"
```

## 核心原则

- 事实优先级：正式参考图 > 正式资产索引 > 场景母版 > 相邻正式帧 > 文字Prompt > 旧版本。
- 角色、道具和场景必须先分别建立锚点，再生成叙事关键帧。
- 所有“左/右”都同时写人物自身解剖学方向和画面方向。
- 每张关键帧只表达一个最重要的静态瞬间。
- 单次修订只改一个明确问题，其他内容列为强制不变量。
- 新版本递增编号，不覆盖旧版本。
- 画面中的文字、字幕、标志和复杂界面默认留空，后期合成。

## 目录说明

- `project_template/`：复制到新项目后直接填写的完整模板。
- `scripts/`：新建项目、检查资产和生成联系表的PowerShell脚本。
- `examples/`：可删除的示例，只用于理解填写方式，不参与新项目生成。

## 当前项目示例

`examples/把答案写在大地上/`保存了一个完成案例的项目记忆、资产索引和两张快速视觉引用板。核心模板不依赖此示例，删除整个`examples`目录不影响工具包使用。

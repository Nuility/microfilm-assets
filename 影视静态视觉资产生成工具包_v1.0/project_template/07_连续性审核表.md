# 《{{PROJECT_NAME}}》连续性审核表

## 问题等级

- A级硬错误：身份错误、左右手错误、道具复制/消失、场景拓扑变化、动作因果断裂、时间或光向逆序。必须重制。
- B级明显漂移：脸部相似度下降、服装剪裁变化、道具比例改变、建筑材质漂移。原则上重制。
- C级软风险：动作桥未展示、背景细节轻微变化、不影响剧情的构图差异。记录后决定是否补帧。

## 角色检查

- [ ] 同一脸部和年龄
- [ ] 发型、分缝和长度一致
- [ ] 服装颜色、剪裁和材质一致
- [ ] 身高体型和人物间比例一致
- [ ] 固定痣、疤、眼镜、手表、包等位置一致
- [ ] 人物自身左右侧与画面方向均已核对

## 空间检查

- [ ] 门窗位置与数量一致
- [ ] 固定家具和设施未换位
- [ ] 入口、出口和人物动线成立
- [ ] 前中后景比例合理
- [ ] 摄影机换位没有造成伪反打或错误跳轴
- [ ] 建筑尺度和透视真实

## 道具与动作检查

- [ ] 道具造型与正式参考图一致
- [ ] 道具数量正确
- [ ] 持有者、持物手和交接顺序正确
- [ ] 道具出现与消失有因果
- [ ] 手指、腕部和抓握关系真实
- [ ] 动作能连接前后正式帧

## 时间与光线检查

- [ ] 剧情时间单向推进
- [ ] 天气和地面状态连续
- [ ] 主光方向连续
- [ ] 色温变化渐进
- [ ] 灯具开关时机正确
- [ ] 室内外曝光关系合理

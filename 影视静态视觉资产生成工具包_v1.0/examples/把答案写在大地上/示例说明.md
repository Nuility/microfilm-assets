# 完成案例说明

本目录仅用于展示通用模板填写完成后的样子，可整体删除。

- `完成案例_项目记忆.md`：展示如何压缩剧情事实、角色锁定、道具流、场景拓扑、提示词和审核规则。
- `完成案例_资产索引.json`：展示36张正式关键帧、角色、道具、场景母版与QA文件的机器可读映射。
- `完成案例_角色与道具.jpg`：展示角色和核心道具快速引用板。
- `完成案例_场景空间.jpg`：展示多个场景空间母版快速引用板。

注意：案例索引中的绝对路径属于原项目，只用于说明字段结构。新项目必须运行建项脚本并填写自己项目中的相对路径。

## 从案例中提炼出的通用经验

1. 角色照片只能解决身份一致性，无法替代场景母版。
2. 空间连续性需要记录画面左、中、右和前、中、后景，而不是只写“同一地点”。
3. 左右侧必须写人物自身方向，同时描述其在画面中的位置。
4. 高频关键道具必须单独生成档案图，再进入剧情画面。
5. 微距手部和道具镜头比普通中景更容易暴露形状漂移，必须单独审核。
6. 联系表适合发现跨镜头身份、服装、色温和场景漂移，但不能代替原分辨率检查。
7. 正式版本必须由索引指定，不能简单选择文件夹中版本号最高的文件。

# 《把答案写在大地上》场景逻辑母版与画面审核标准

版本：v1.0  
用途：作为角色设定图与全部镜头关键帧的唯一空间、动作、道具和光线连续性判据。

## 1. 全片硬性连续性规则

### 1.1 人物左右侧（均指人物自身的解剖学左右，不按画面左右判断）

- 林悦：米白帆布单肩包固定在**左肩**；窄黑色电子表固定在**右腕**；黑色三轴手机稳定器原则上由**右手**持握。
- 林悦：左眼下方的小痣必须保留；黑色低马尾、雾霾蓝短款冲锋衣、米白针织衫、深灰直筒裤、米白帆布鞋不变。
- 周建国：左手拇指与食指虎口处有一道浅色旧疤；蓝色手帕固定在棕色旧夹克左胸袋。
- 陈老师：银色细框眼镜、齐肩内扣黑发、深藏蓝西装不变。

### 1.2 核心道具

- P01 笔记本：暗红色 A5 硬壳本，书脊和封面磨损一致。
- P03 手机稳定器：黑色三轴手持云台，安装一部深灰色、无品牌标识的智能手机；手机固定为横屏。禁止替换为运动相机、摄影机或裸云台。
- P06 旧钥匙：一把长柄黄铜老式齿钥匙，椭圆形钥匙环、长钥匙杆、明确的老式齿口，系褪色红棉绳。全片只出现这一把，不得变成现代短钥匙。

### 1.3 钥匙流转

1. S03 木屋内：钥匙最初在周建国掌控中，离开木屋前收入夹克左侧口袋。
2. KF25：周建国用带虎口旧疤的左手把同一把钥匙交给林悦，林悦以双手承接。
3. KF26：林悦双手托住同一把钥匙，从钥匙抬眼看向居民楼入口。
4. KF27：林悦写笔记时，同一把钥匙平放在暗红色笔记本左上角。
5. KF28：林悦将同一把钥匙交还周建国；周建国以左手接回并准备离开。
6. 全片不得出现复制钥匙；KF28 后钥匙归周建国管理。

## 2. 场景空间母版

### S01/S05 大学阶梯教室

- 采用现有通过镜头形成的固定空间：黑板在画面左侧，投影幕在右侧，讲台居中偏前，窗户沿右墙排列，入口门位于左侧。
- S01 为下午自然光，教室顶部灯光弱或关闭；S05 为傍晚转蓝调，投影幕成为主要视觉光源，顶部灯可辅助开启。
- S05 必须继承 S01 的讲台、座位、黑板、投影幕和窗户方位，不能镜像翻转。

### S02 教学楼走廊

- 左侧为教室门，右侧为窗/栏杆和室外采光。
- 离开教室时人物远离镜头向楼梯方向走；返回教室时人物朝镜头或朝左侧门移动。
- 下午光线从右侧进入，人物投影方向稳定。

### S03 老街巷口与木屋

- 动线固定为：老街巷道 → 深色木门 → 木屋室内。
- 木屋内部：中央旧木桌；左侧旧照片墙；右侧窗户；后侧矮柜；入口门位于靠镜头一侧。
- 进入：从巷道推门，人物从门外进入室内。
- 离开：摄影机应在室内或侧后方，人物背对镜头走向门外；不得拍成从室外走向镜头、再次进入木屋。

### S04 社区共享庭院

- 从木屋出口进入庭院后，空间关系固定：中央为梧桐树；左侧为无障碍坡道与银色扶手；后方红砖楼外立面安装外置电梯；右侧为社区阅读室；树下有长椅；阅读室附近有一盏庭院灯。
- 太阳位于画面右上方，阴影落向左下方；时间从 16:35 推进至 17:00，色温逐渐变暖、亮度逐步降低。
- 庭院灯在 KF30 前不发光，KF30 才明确点亮。

## 4. 审核判定优先级

- A 级硬错误：人物身份或左右侧错误、关键道具形态错误、人物进出方向错误、场景拓扑镜像、时间/灯光与剧情冲突。必须重制。
- B 级连续性错误：局部道具位置漂移、背景设施辨识不足、服装小范围偏色。建议修订。
- C 级审美差异：不影响叙事和连续性的构图或细节差异。可以保留。

## 6. 重制验收标准

- 重制图必须同时通过：角色身份、左右侧、服装、道具形态、空间方向、动作目的、时间光线七项检查。
- 所有修订采用新版本号 `v02`，保留 `v01` 作为审核追溯，不覆盖原文件。
- 若新图修正逻辑却引入更严重的人脸或构图漂移，则不升级为正式版本，继续迭代。
